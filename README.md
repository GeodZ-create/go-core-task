# go-core-task

Репозиторий с решениями 9  задач по Go. Каждая задача находится в отдельной папке и сопровождается тестами.

## Структура проекта

```text
.
├── go.mod
├── 1/
├── 2/
├── 3/
├── 4/
├── 5/
├── 6/
├── 7/
├── 8/
└── 9/
```

В каждой директории лежат:

- файл с решением;
- файл с unit-тестами.

## Описание задач

### 1. Базовые типы, строки и хеширование

Реализованы функции для:

- определения типа значения;
- конкатенации значений разных типов в строку;
- преобразования строки в `[]rune`;
- вставки "соли" в середину строки;
- получения SHA-256 хеша.

### 2. Работа со слайсами

Реализованы операции:

- выборка только чётных чисел из слайса;
- добавление элемента;
- копирование слайса без связи с оригиналом;
- удаление элемента по индексу с обработкой ошибки.

### 3. Обёртка над map

Создан тип `StringIntMap` с методами:

- `Add`
- `Remove`
- `Copy`
- `Exists`
- `Get`

### 4. Формирование нового слайса

Функция `NewSlice`:

- принимает два слайса строк;
- возвращает результат без пересечений первого со вторым слайсом.

### 5. Поиск пересечений двух слайсов

Функция `MatchesSlice`:

- ищет общие элементы двух слайсов;
- возвращает флаг наличия совпадений;
- убирает дубликаты в результирующем слайсе.

### 6. Генератор случайных чисел через канал

Функция `randNumGenerator`:

- запускает горутину;
- отправляет заданное количество случайных чисел в канал;
- закрывает канал после завершения генерации.

### 7. Объединение нескольких каналов

Функция `joinChannels`:

- принимает несколько входных каналов;
- читает данные параллельно;
- объединяет значения в один выходной канал;
- закрывает результирующий канал после завершения всех источников.

### 8. Простой semaphore/wait group

Реализован собственный тип `semaphore`:

- `NewSemaphore(n int)` создаёт буферизированный канал;
- `Done()` сигнализирует о завершении;
- `Wait(n int)` ждёт указанное число завершений.

### 9. Pipeline с каналами

Реализован простой конвейер:

- `FirstChan(nums ...uint8)` передаёт числа в канал;
- `Cubing(in <-chan uint8)` читает числа и возвращает их кубы;
- в `main` результат собирается, сортируется и выводится.

## Тестирование

Запуск всех тестов:

```bash
go test ./...
```

Запуск тестов конкретной задачи:

```bash
go test ./5
```

